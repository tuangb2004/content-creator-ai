## BẢNG NHẬT KÝ THỰC TẬP

| Thời gian | Nội dung thực tập (Kế hoạch) | Kết quả thực hiện | Ghi chú |
|-----------|------------------------------|-------------------|---------|
| **Tuần 1 + 2** (Từ 10/11/2025 đến 23/11/2025) | - Tìm hiểu quy trình nghiệp vụ hệ thống hỗ trợ sáng tạo nội dung. - Phân tích yêu cầu chức năng: Tạo nội dung AI, Quản lý dự án, Hệ thống thanh toán. - Cài đặt môi trường: Node.js, Firebase CLI, VS Code, Git. | - Nắm rõ luồng nghiệp vụ của người dùng và quản trị viên. - Xác định danh sách chức năng (Feature List). - Cài đặt xong môi trường phát triển và cấu hình Firebase project. | Được đơn vị thực tập phổ biến nội quy, cách thức làm việc. Làm quen với công nghệ ReactJS, Firebase. |
| **Tuần 3 + 4** (Từ 24/11/2025 đến 07/12/2025) | - Thiết kế Cơ sở dữ liệu NoSQL (Firestore). - Xây dựng các Collection chính: users, projects, posts, transactions, videoQueue. - Vẽ biểu đồ Use Case tổng quát. | - Hoàn thành thiết kế schema Firestore và tạo collections. - Xây dựng xong sơ đồ Use Case cho hệ thống (Admin, User, Guest). - Thiết lập Firestore Security Rules. | Sử dụng cấu trúc NoSQL document-based, đảm bảo quan hệ dữ liệu phù hợp. |
| **Tuần 5 + 6** (Từ 08/12/2025 đến 21/12/2025) | - Xây dựng Backend với Firebase Cloud Functions (TypeScript). - Viết API xác thực (Login/Register với Email, Google, Facebook). - Viết API cho generateContent và saveProject. - Cấu hình Firebase Authentication. | - API Đăng nhập/Đăng ký hoạt động tốt với nhiều phương thức OAuth. - Hoàn thành API tạo nội dung văn bản với Gemini và Groq. - Test thành công các Cloud Functions. | Nắm rõ Serverless Architecture. Tuân thủ kiến trúc Cloud Functions best practices. |
| **Tuần 7 + 8** (Từ 22/12/2025 đến 04/01/2026) | - Xây dựng Frontend bằng ReactJS + Vite. - Thiết kế giao diện: Landing Page, Dashboard, Agent Chat, Inspiration. - Tích hợp Firebase SDK và gọi Cloud Functions. - Áp dụng Tailwind CSS cho styling. | - Giao diện hiển thị tốt, responsive trên mobile/tablet/desktop. - Người dùng có thể chat với AI và xem kết quả. - Đã kết nối dữ liệu từ Firestore lên Frontend. - Hoàn thành dark mode và đa ngôn ngữ (i18n). | Sử dụng Tailwind CSS và Lucide React icons. Áp dụng React Context cho state management. |
| **Tuần 9 + 10** (Từ 05/01/2026 đến 18/01/2026) | - Tích hợp module AI tạo hình ảnh (Stability AI/SDXL). - Tích hợp Veo 3.1 API cho tạo video. - Xây dựng hệ thống hàng đợi video (videoQueue). - Tích hợp PayOS cho thanh toán và nạp credit. | - Kết nối thành công API Stability AI và Veo 3.1. - Hệ thống tự động xử lý hàng đợi video với PubSub. - Tích hợp PayOS webhook xử lý thanh toán thành công. - Hoàn thành trang Inspiration với like, save, share. | Tối ưu prompt engineering cho AI. Xử lý rate limiting và error handling. |
| **Tuần 11 + 12** (Từ 19/01/2026 đến 31/01/2026) | - Hoàn thiện các chức năng còn lại (Profile Settings, TikTok OAuth). - Kiểm thử toàn bộ hệ thống (Integration Test). - Sửa lỗi (Bug fixing) và tối ưu hiệu năng. - Deploy lên Vercel và Firebase Hosting. - Viết báo cáo và chuẩn bị slide bảo vệ. | - Hệ thống hoạt động ổn định trên production. - Deploy thành công lên Vercel (Frontend) và Firebase (Backend). - Hoàn thành báo cáo khóa luận. - Chuẩn bị demo dự án. | Kết thúc kỳ thực tập. Website live tại: content-creator-ai-wheat.vercel.app |
